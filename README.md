## Why

I enjoy home-brewed VoIP System with [my companion](https://zenn.dev/kusaremkn/articles/abd760f9f2f450), but I have a life in the real world and can't always pick up the phone.

Surely, you can set up built-in (or scripted) answer machine using SIP Server as MikoPBX etc., but the process is not clarity so I always ask to acquaintance. The inability to separate the SIP Server from the system also makes it diffucult to handle.

This is why I made this tools.

## Naming Sense

If you feel `waitress` is not satisfied, you can use `ailas`.

```sh
alias waiter="waitress"
```
